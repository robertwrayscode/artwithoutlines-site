# artwithoutlines.org

Temporary website for Art Without Lines (AWL), a Houston-based nonprofit in formation providing free, unstructured art spaces for children.

Live at: https://artwithoutlines.org

## Files

- index.html - Home
- about.html - About
- mission.html - Mission and core beliefs
- get-involved.html - Volunteer roles and future programs
- contact.html - Email and mailing address
- styles.css - Shared stylesheet

## Stack

Plain HTML and CSS. No build step, no framework. Google Fonts (Fraunces and Inter) loaded from Google CDN.

## Hosting

Bluehost. Document root is /public_html/website_8b865670/. See BLUEHOST-UPLOAD.md for the upload procedure.

## Status

Placeholder site while AWL incorporates in Texas and applies for 501(c)(3) status.
